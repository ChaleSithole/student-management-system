# Student Management System

## Goal
Build a modern Student Management System using ASP.NET Core MVC and SQL Server.

## Planned Features

- User Authentication
- Student Registration
- Search Students
- Edit Student Information
- Delete Students
- Dashboard
- Reports
- SQL Server Database
- Responsive Interface

## Technologies

- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core
- Bootstrap
- Git
