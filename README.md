# Student Management System

A modern university Student Management System developed using ASP.NET Core MVC and SQL Server.

This project demonstrates full-stack web development using Microsoft's technology stack while following the MVC architecture and clean service-based design.

---

# Features

## Authentication

- ASP.NET Identity
- Administrator Login
- Lecturer Login
- Role-Based Authorization

---

## Dashboard

- Student Statistics
- Faculty Statistics
- Programme Statistics
- Active Students
- Quick Actions

---

## Student Management

- Create Students
- Edit Students
- Delete Students
- View Details
- Search
- Sorting
- Filtering
- Pagination

---

## Faculty Management

- Create Faculties
- Edit Faculties
- Delete Faculties
- Prevent deleting faculties with programmes

---

## Programme Management

- Create Programmes
- Edit Programmes
- Delete Programmes
- Prevent deleting programmes with enrolled students
